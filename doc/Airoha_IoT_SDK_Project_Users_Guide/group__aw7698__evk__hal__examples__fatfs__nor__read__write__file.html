fatfs_nor_read_write_file
aw7698_evk » hal_examples
Overview
  • Application description
    • This application demonstrates how to use FatFS to access a file stored on nor flash.
    • The application does not require FreeRTOS.
  • Results
    • Log will show whether the file is read and written successfully.
Hardware and software environment
  • Supported platform
    • AW7698 EVK.
  • Environment configuration
    • The output logs are communicated through a type-A to micro-B USB cable to the PC from USB (CON5) connector on the EVK.
    • Install the mbed serial driver according to the instructions at https://developer.mbed.org/handbook/Windows-serial-configuration. For more information, please refer to section "Installing the "AW7698 EVK drivers on Microsoft Windows" on the "AW7698 EVK User Guide" in [sdk_root]/doc folder.
    • Use a type-A to micro-B USB cable to connect type-A USB of the PC and CON5 micro-B USB connector on the AW7698 EVK. For more information about the connector cable, please refer to https://en.wikipedia.org/wiki/USB#Mini_and_micro_connectors.
    • Launch a terminal emulator program, such as Tera terminal on your PC for data logging through UART. For the installation details, please refer to section "Installing Tera terminal on Microsoft Windows" on the "Airoha IoT SDK Get Started Guide" in [sdk_root]/doc folder.
    • COM port settings. baudrate: 115200, data bits: 8, stop bit: 1, parity: none and flow control: off.
Directory contents
  • Source and header files
    • src/main.c: Main program.
    • src/system_aw7698.c: AW7698 clock configuration file.
    • inc/hal_feature_config.h: AW7698 feature configuration file.
    • inc/memory_map.h: AW7698 memory layout symbol file.
    • GCC/startup_aw7698.s: AW7698 startup file for GCC.
    • GCC/syscalls.c: AW7698 syscalls for GCC.
  • Project configuration files using GCC
    • GCC/feature.mk: Feature configuration.
    • GCC/Makefile.: Makefile.
    • GCC/aw7698_flash.ld: Linker script.
Run the example
  • Build the example project with the command "./build.sh aw7698_evk fatfs_nor_read_write_file" from the SDK root folder and download the binary file to AW7698 EVK.
  • Connect the EVK to the PC with a type-A to micro-B USB cable, and open the port with the name "mbed Serial Port".
  • Run the application. The transaction result is displayed in the log and "The file is written and read successfully!" indicates a successful access to a file.
