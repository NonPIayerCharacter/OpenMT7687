pwm_generate_waveform
aw7698_evk » hal_examples
Overview
  • Example description
    • This example is a reference application to demostrate the use of PWM APIs to genarate PWM signal on EX_GPIO_2.
  • Results
    • The log will show whether the EX_GPIO_2 output PWM successfully.
Hardware and software environment
  • Supported platform
    • AW7698 EVK.
  • HDK switches and pin configurations
    • Make sure EX_GPIO_2 is disconnected.
  • Environment configuration
    • The output logs are communicated through a micro-USB cable to the PC from USB (CON5) connector on the EVK.
      • Install the mbed serial driver according to the instructions at https://developer.mbed.org/handbook/Windows-serial-configuration. For more information, please refer to section "Installing the AW7698 EVK drivers on Microsoft Windows" on the "AW7698 EVK User Guide" in [sdk_root]/doc folder.
      • Use a type-A to micro-B USB cable to connect type-A USB of the PC and MK20 micro-B USB connector on the AW7698 EVK. For more information about the connector cable, please refer to https://en.wikipedia.org/wiki/USB#Mini_and_micro_connectors.
      • Launch a terminal emulator program, such as Tera terminal on your PC for data logging through UART. For the installation details, please refer to section "Installing Tera terminal on Microsoft Windows" on the "Airoha IoT SDK Get Started Guide" in [sdk_root]/doc folder.
      • COM port settings. baudrate: 115200, data bits: 8, stop bit: 1, parity: none and flow control: off.

    • src/wifi_lwip.c LwIP configuration.
    • src/bt_init.c: Bluetooth memory initialization and task creation.
    • src/hci_log.c: Bluetooth HCI log file. The user must initiate the UART port for HCI logging.
    • src/ut_app/.: Bluetooth CLI command handler.
    • inc/bt_init.h: Declare the Bluetooth task create API.
    • inc/cli_cmds.h Declares the reference point of CLI commands of cli_cmds.c. To be used by cli_def.c
    • inc/FreeRTOSConfig.h AW7698 FreeRTOS configuration file.
    • inc/ept_eint_drv.h The EINT configuration file generated by Easy Pinmux Tool(EPT). Please do not edit the file.
    • inc/ept_gpio_drv.h The GPIO configuration file generated by Easy Pinmux Tool(EPT). Please do not edit the file.
    • inc/flash_map.h AW7698 memory layout symbol file.
    • inc/hal_feature_config.h AW7698 HAL API feature configuration file.
    • inc/lwipopts.h LwIP configuration.
    • inc/hci_log.h: Declare the Bluetooth HCI log API.
    • inc/project_config.h: Define the maximum number of Bluetooth connections and timer. And define the buffer size of the TX/RX, timer and connection.
    • inc/sys_init.h Prototype declaration for src/sys_init.c.
    • inc/task_def.h The configuration of running tasks of the project.
    • inc/wifi_lwip.h Prototype declaration for src/wifi_lwip.c.

    • GCC/feature.mk Generic feature options configuration file.
    • GCC/aw7698_flash.ld Linker script.
    • GCC/startup_aw7698.s AW7698 startup file.
    • GCC/syscalls.c AW7698 syscalls implementation.
Run the example
  • Build the example project and download the binary file to AW7698 EVK.
  • Connect the EVK to the PC with a USB cable.
  • Run the example. The message "example project test success" indicates a successful operation.
