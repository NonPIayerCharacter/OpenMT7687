enum pta_antenna_mode_t

This enumeration defines the antenna mode in coexistence.

Enumerator
PTA_ANT_MODE_SINGLE 

Single antenna mode; Wi-Fi and BT share the same antenna.

Single antenna mode is only used in TDD.

PTA_ANT_MODE_DUAL 

Dual antenna mode; Wi-Fi and BT have an independent antenna.

Dual antenna mode is used in both TDD and FDD.

enum pta_cm_mode_t

This enumeration defines the coexistence mode.

Enumerator
PTA_CM_MODE_TDD 

Time Division Duplex (TDD) is a scheduled coexistence mode.

PTA_CM_MODE_FDD 

Frequency Division Duplex (FDD) is an unscheduled coexistence mode.

It is not supported.

enum pta_mode_t

This enumeration defines the PTA mode.

Note
The choice of pta_mode_t must be based on the Wi-Fi and BT chip's PTA capability. For Airoha Wi-Fi and BT chips, the PTA pins must be set in the EPT file which can refer to the hardware reference design.
Enumerator
PTA_MODE_1_WIRE 

1-wire PTA mode.

It is not supported.

PTA_MODE_1_WIRE_EXTENDED 

1-wire extended PTA mode.

It is not supported.

PTA_MODE_3_WIRE 

3-wire mode.
